AI Tic-Tac-Toe

A neural-network-themed tic-tac-toe game built with ClojureScript and Reagent.

About this project

An enhanced version of the classic Tic-Tac-Toe game featuring an animated neural network background, multiple difficulty levels, and a sleek dark UI. Built with ClojureScript, Reagent, and HTML5 Canvas.

A test-driven tic-tac-toe engine built in C# with .NET 8, featuring minimax AI with alpha-beta pruning. This is the browser frontend for the same game logic that also runs as a CLI app and ASP.NET Web API.

About this project

Built test-first with xUnit, the C# version implements the full game engine as a class library: an extensible NxN board, pluggable player strategies via an IPlayer interface, and an unbeatable minimax AI with alpha-beta pruning. The same core library powers a CLI app, an ASP.NET Web API, and this standalone JavaScript port of the game logic.
