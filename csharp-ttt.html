C# Tic-Tac-Toe

A test-driven tic-tac-toe engine built in C# with .NET 8, featuring minimax AI with alpha-beta pruning.

About this project

Built test-first with xUnit, this project implements the full game engine as a class library: an extensible NxN board, pluggable player strategies via an IPlayer interface, and an unbeatable minimax AI with alpha-beta pruning. The same core library powers a CLI app, an ASP.NET Web API, and this standalone JavaScript port of the game logic.
